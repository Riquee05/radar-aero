# Logos das companhias

Uso identificativo, sem vínculo ou endosso das marcas. Os arquivos são fornecidos pelas páginas abaixo como PD-textlogo; os direitos de marca continuam com seus titulares.

- Azul Linhas Aéreas Brasileiras: https://commons.wikimedia.org/wiki/File:Logo_da_Azul_Linhas_A%C3%A9reas_Brasileiras.svg — autor: Azul Linhas Aéreas Brasileiras; fonte original voeazul.com.br.
- LATAM: https://commons.wikimedia.org/wiki/File:Latam-logo_-v_(Indigo).svg — desenho Interbrand, vetorização Mliu92; variante Indigo.
- GOL: https://commons.wikimedia.org/wiki/File:Gol_Linhas_A%C3%A9reas_Inteligentes_logo_(2015,_with_slogan).svg — autor GOL Linhas Aéreas Inteligentes, fonte original voegol.com.br; versão com slogan.

Arquivos originais preservados; somente dimensionados na interface. Consulta em 02/11/2026.

A associação usa apenas os prefixos ICAO TAM, AZU e GLO de indicativos válidos. Isso não confirma origem/destino nem identifica todos os operadores ou voos compartilhados. Matrículas, códigos desconhecidos e indicativos ausentes mantêm ícone neutro. Logos são servidos localmente, sem API de marcas ou rastreamento remoto.
